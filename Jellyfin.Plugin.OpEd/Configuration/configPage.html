Anime opening and ending themes from a folder you fill, matched to your shows, for clients that use the OP/ED API (for example AsterFIN). Jellyfin's own theme music/video playback is not affected.

Themes folder

One folder per show, named exactly like the show's folder in your media library. Inside it: OP1.webm, OP1.ogg, ED2.webm … (AnimeThemes file names such as SousouNoFrieren-OP1.webm work too). Optional subfolders: Season 2 to limit a theme to that season, or anidb-18886 for one exact AniDB entry. Keep this folder outside every library, so no library picks the themes up as ordinary videos.

Metadata

Uses the AniDB IDs on your seasons (Shokofin sets them). Answers are cached.
